# can-albayrak.github.io

Public site for Can Albayrak's games, served by GitHub Pages.

- `index.html`, `tilt-grid/`, `fuse-chain/`, `cuddle-pop/`: privacy policies, generated by
  `python privacy-site/build.py` from each game repo's `docs/PRIVACY_POLICY.md`. Do not edit them by hand.
- `marketing/`: store screenshot and video clip tools, and the posting plan (see `marketing/README.md`).

The game repos (private) must sit next to this repo for the scripts to find them.
